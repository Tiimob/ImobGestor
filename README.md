# Gestão RH → TI — Even

Ferramenta web interna para padronizar a comunicação de movimentações de corretores entre **RH e TI**.

## Empresas atendidas

- Even Vendas
- Even RJ

> A antiga opção **Even More** foi removida da ferramenta.

## Processos

- **Credenciamento** — entrada de novo corretor e solicitação dos acessos.
- **Atualização cadastral** — alteração de dados ou informações do corretor.
- **Descredenciamento** — remoção de acessos e apoio ao fluxo de rescisão.

## Principais recursos

- Interface responsiva para desktop e celular.
- Seleção consistente dos corretores que participarão da ação.
- Validação de campos obrigatórios e formato de e-mail.
- Tela de revisão antes de gerar o e-mail para o TI.
- Geração de e-mail padronizado via `mailto:`.
- Exportação CSV compatível com Excel, em UTF-8.
- Geração de comunicado de rescisão para registros selecionados.
- Nenhum backend ou banco de dados: os dados permanecem apenas na sessão do navegador.

## Segurança

Não registre senhas, tokens, códigos de autenticação ou outras credenciais na ferramenta.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro

## Publicação

O projeto pode ser publicado diretamente no GitHub Pages. Mantenha o arquivo `index.html` na raiz do repositório junto dos arquivos de imagem e favicon.
